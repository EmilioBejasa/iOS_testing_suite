# Security

This is a testing-helper kit and a demo app with no backend, no user data
collection, and no production service — the realistic security surface is
narrow (e.g. a dependency vulnerability, or a `Mock`/`System` type that
accidentally does something unsafe with real device data).

If you find a security issue, please report it privately via [GitHub Security
Advisories](https://github.com/EmilioBejasa/iOS_testing_suite/security/advisories/new)
rather than opening a public issue. We'll acknowledge reports as soon as
possible.
